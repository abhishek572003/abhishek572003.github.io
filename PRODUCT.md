# Product

Personal academic website of Abhishek Sunil Tiwari (abhishek572003.github.io).

## Platform
web

## Stack
Delegated to the agent: React + Vite, built to static files, deployed free on GitHub Pages.

## Users
1. US computer-science professors (primary). They open the link from a cold email or a Fall 2027 PhD application, usually on a laptop between meetings, and spend 30–90 seconds deciding if he is worth a reply or interview.
2. Industry recruiters (secondary), for cloud / DevOps / security roles.

## Product Purpose
Make a reader remember him as a cloud-and-edge security researcher in the making, with real systems experience, and make it easy to reply, read the CV, or check the code.

## Positioning
Not a generic student portfolio. The difference: he has built and run production cloud infrastructure (IAM, TLS, CI/CD, multi-tenant AWS), and he has an ongoing, honest research study (are AI coding agents introducing security misconfigurations into Terraform/Kubernetes?) with a public research log.
