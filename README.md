# abhishek572003.github.io

Personal academic website. React + Vite + Three.js + GSAP, deployed by GitHub Actions on every push to `main`.

- Edit text: `src/content.js`
- 3D model: `src/scene.js`
- Run locally: `npm install`, then `npm run dev`
- Replace the CV: overwrite `public/assets/Abhishek_Tiwari_Academic_CV.pdf`
